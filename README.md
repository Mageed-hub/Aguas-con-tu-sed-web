## 📌 Sobre el Proyecto

**Aguas con tu sed** es una plataforma web moderna y sofisticada diseñada para un negocio de bebidas artesanales, aguas frescas y snacks. El sitio web destaca por una interfaz limpia, navegación intuitiva y un enfoque completamente centrado en mejorar la experiencia del usuario (UX) al explorar el menú y gestionar sus pedidos.

> 🌐 **Despliegue en Vivo:** El proyecto se encuentra completamente optimizado y alojado de forma pública. Puedes explorar la experiencia interactiva aquí:  
> 👉 **[https://mageed-hub.github.io/Aguas-con-tu-sed-web/](https://mageed-hub.github.io/Aguas-con-tu-sed-web/)**

---

## 🗺️ Arquitectura de Navegación

El sitio está desarrollado bajo una estructura modular compuesta por **4 módulos HTML dinámicos**, completamente interconectados:

| Archivo | Módulo / Sección | Descripción Funcional |
| :--- | :--- | :--- |
| `index.html` | 🏠 **Landing Page** | Página de inicio con banners de alto impacto visual, propuesta de valor corporativa y accesos rápidos a las especialidades. |
| `carta.html` | 📋 **Menú Digital** | Catálogo interactivo de productos organizado por categorías (Aguas del día, Especialidades, Snacks) con precios y descripciones. |
| `carrito.html` | 🛒 **Gestión de Pedidos** | Interfaz del carrito de compras que procesa la selección de productos, desglosa subtotales, impuestos y prepara el flujo de pago. |
| `nosotros.html` | 👥 **Identidad Corporativa** | Sección institucional que expone la historia, misión, visión y los valores fundamentales que respaldan la calidad de la marca. |

---

## ✨ Características Principales

* 🎨 **Identidad de Marca Sólida:** Uso de una paleta de colores fresca y coherente con el sector gastronómico.
* 📱 **Navegación Fluida:** Enlaces semánticos e interconexión sin fisuras entre el catálogo y el carrito de compras.
* 📦 **Organización de Recursos:** Estructura limpia con una carpeta `/imagenes` dedicada para optimizar los tiempos de carga del servidor.
* 💎 **UI Limpia:** Uso de tipografías legibles y componentes visuales diseñados para cautivar la atención del cliente.

---

## 🛠️ Stack Tecnológico

* **Maquetación Estructurada:** HTML5 Semántico para un mejor posicionamiento y accesibilidad.
* **Estilos e Interfaz:** CSS3 con técnicas modernas de distribución de elementos y diseño adaptable.
* **Componentes Gráficos:** Integración de fuentes web estilizadas y recursos optimizados para la nube.
